# Landing page – Balles Tech Energia

Página estática (HTML + CSS + JS num único `index.html`, imagens em `img/`). Não precisa de build.

- **WhatsApp, tarifa e parâmetros do simulador:** constante `CONFIG` no fim do `index.html`.
- **Depoimentos:** substituir os blocos `[DEPOIMENTO REAL AQUI]`.
- **Publicação:** Hostinger → Avançado → Git, apontando para a branch `main` e a pasta `public_html`.
