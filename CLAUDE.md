# Regras de trabalho

## Autonomia e ações irreversíveis
- **Nunca faça nada irreversível sem aprovação explícita do usuário.** Antes, explique o que vai fazer, o que se perde e peça um "sim".
  Exemplos: apagar site, arquivos, banco de dados, e-mails ou caixas de e-mail; resetar ou apagar DNS inteiro; cancelar ou alterar planos; force-push ou apagar branches; qualquer compra ou pagamento.
- **O que for reversível, faça direto, sem pedir permissão.** Exemplos: criar sites, publicar/atualizar páginas (o GitHub guarda as versões), ajustar registros DNS do site (anotando os valores antigos), instalar SSL, ler dados, editar código, fazer commit e push em branch.
- Compras e pagamentos sempre ficam com o usuário.
